# LeafCode

LeafCode is a coding challenge platform where solutions are ranked by energy consumption, encouraging developers to write correct, efficient, and environmentally sustainable code.

Unlike traditional platforms that try to optimize for execution time or memory, our solution is LeafCode which ranks solutions based on energy consumption (Joules). After submitting a solution, user code is executed in a sandboxed environment, CPU usage is monitored, and energy is estimated using a machine learning power model from cloud-energy. Correct solutions are then scored and ranked by how little energy they consume.

The goal is simple: shift developer thinking from “fastest code wins” to “most sustainable code wins.”
